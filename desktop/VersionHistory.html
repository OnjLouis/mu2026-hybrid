MU2000 Version History

1.0.1

New project saves compress the full emulator state without losing data. Existing projects and presets still load. Reopen and save an older project to let the host write the smaller state. Logic Pro may retain large plug-in snapshots in its undo history. On a backed-up copy, use Edit > Delete Undo History, then save. This removes undo and redo steps, and the host may still retain other snapshots. Older plug-in versions cannot read the new compressed state.

1.0.0

First desktop release for Apple Silicon Mac and Windows x64: standalone MIDI playback, VST3, Mac Audio Unit, keyboard and screen-reader controls, and on-demand Komplete Kontrol and VST3 preset generation. Adds in-app verified installer downloads. Existing plug-in identifiers are retained.
